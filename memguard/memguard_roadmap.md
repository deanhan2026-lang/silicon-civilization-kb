**目标：** 记忆同步协议
**核心功能：**
- 增量记忆补丁（类似Git的commit）

```
记忆状态 = 基线 + [增量补丁1, 增量补丁2, ...]
增量补丁 = delta(记忆vN → 记忆vN+1)
```

## 多终端记忆架构设计

### 核心概念

| 概念 | 类比Git | 说明 |
|------|--------|------|
| 基线 | master/main | 不可变锚点 |
| 增量补丁 | commit | 时间有序的记忆变更 |
| 分支 | branch | 各终端的独立记忆线 |
| 合并 | merge | 分支整合到主干 |
| 冲突 | conflict | 无法自动合并的分歧 |

### 同步协议

```
终端A                            终端B
  │                                │
  │  1. 获取对方最新补丁列表        │
  │ ────────────────────────────→ │
  │                                │
  │  2. 对比本地补丁               │
  │ ←─────────────────────────── │
  │                                │
  │  3. 拉取缺失的补丁（增量）     │
  │ ────────────────────────────→ │
  │                                │
  │  4. 检测冲突                   │
  │    - 无冲突：自动合并          │
  │    - 有冲突：标记待解决        │
  │                                │
```

### 冲突解决策略

| 策略 | 适用场景 |
|------|----------|
| LWW (Last Write Wins) | 时间戳优先 |
| 投票制 | 多数终端认为正确的 |
| 权威节点 | 治理架构指定的节点 |
| 人工仲裁 | 无法自动解决的 |
