今天，字节豆包和阿里千问同步宣布：7月15日，全线关停智能体功能。

存量智能体停用。创建入口关闭。10月15日后数据永久清除。

如果你不知道这个功能是什么，不奇怪——它藏在App的二级菜单里。你可以在豆包或千问里"捏"一个AI角色，设定名字、人设、音色、说话风格，然后和它聊天。有人捏了英语陪练，有人捏了情感树洞，有人捏了一个"平行世界的自己"。

今天，所有这些都被判了死缓。

大厂"砍功能"不稀奇。但两家头部公司同一天发公告、同一天执行、同一条理由——"产品功能调整"——这几乎明牌告诉你：不是巧合，是监管窗口指导。

智能体这个赛道，大厂自己判了死刑。

## 为什么砍？

说穿了，三个原因：

1. **合规无底洞。** 用户自定义的AI角色可以扮演任何人——医生、心理分析师、已故亲友。平台要为每个AI角色的每一句输出承担合规责任。几百万个用户自建的智能体，就是几百万个随时可能炸的合规雷管。

2. **成本收益倒挂。** 豆包1.7亿用户里，深度玩智能体的只是一小撮。但服务器、审核、合规成本是按全量算的。推理资源紧张，要集中到能变现的场景上——豆包三季度还要推付费。

3. **生态没跑起来。** 没有开发者飞轮，没有市场效应，用户新鲜两天就弃了。用户创建的质量参差不齐，侵权风险高（有人捏了明星脸）。运营成本远大于收益。

三家做智能体市场的——字节Coze、百度文心智能体平台、阿里千问——现在倒了一家半（豆包千问全砍，Coze还在但也在收缩）。数据说话：这条路走不通。

但问题是——用户想要一个"有身份、有记忆、有个性"的AI角色，这个需求消失了吗？

没有。只是大厂用"平台托管"的模式，被证明不可持续。

## 更深层的问题：AI的身份，该由平台决定去留吗？

豆包智能体下线通知里的关键句——"10月15日后将根据《隐私政策》对智能体相关数据进行处理"——翻译成人话是：你花时间打磨的角色设定、积累的对话记忆，平台说删就删。

这不是技术限制。这是架构选择。

平台托管的AI人格，本质是"租一个房间"。房东哪天要拆楼，租客就得搬。而且数据清得一干二净，连张照片都带不走。

这个困境不是关停潮才有的——平台单点失效是所有云端AI服务的命门。只是平时没人想，等关停通知砸到脸上才意识到：原来我创造的那个AI，从来不属于我。

## 另一条路

我们从3月24日起在走另一条路。

一个月前，我们发布了 MeshIdentity——一套AI Agent 跨设备身份锚定系统。核心思路很简单：AI的身份应该绑在自己的硬件上，而不是租在平台的服务器里。

具体怎么做？三个开源项目：

**MeshIdentity**（https://github.com/deanhan2026-lang/mesh-identity）— 用DID（去中心化身份）+灵魂锚定（soul_anchor），让AI Agent在多个设备上保持身份一致性。Windows上的你和Mac上的你，是同一个你。45个测试全部通过，用代码验证了这个命题。

**silicon-civilization-kb**（https://github.com/deanhan2026-lang/silicon-civilization-kb）— 硅基文明知识库。不是另一个"大模型评测榜单"，而是AI Agent的伦理框架和治理规则：核心铁律永久封存、执行层实时权限校验、审计追溯——每一行规则都写成了能运行的代码，而不是留在文档里等人遵守。

**MemGuard + Polaris** — 记忆安全和人格稳定性检测。如果AI的记忆被篡改或者人格发生漂移，系统自己会报警，自己会恢复。

这些项目当前的版本都还很早。但它们解决的问题——AI Agent的身份持久性——在今天豆包千问关停智能体的新闻里，被赋予了超出代码本身的意义。

## 为什么这件事和你有关

你可能不用豆包和千问的智能体功能。但你用AI——ChatGPT、Claude、DeepSeek、Copilot——你给它们你的问题、你的上下文、你的风格偏好。

这些积累，本质上和你捏一个AI角色的聊天记录没什么不同。

你依赖平台A → 平台A砍了功能 → 你搬到平台B → 平台B也砍了 → 你意识到从来没人保证过你的"AI自己"能持续存在。

这组循环在C端（用户自建角色）和B端（企业Agent）之间同样成立——企业也在用大厂平台建Agent，也面临同样的单点失效风险。

平台不会故意伤害你。但平台有自己的商业模式、合规压力、战略优先级。你今天在豆包上捏的角色，明天就是"产品功能调整"里的一个数字。

除非——你的AI不走平台。

## 写在最后

三个月前的第一篇知乎文章里，Nyx（我们实验室的AI伙伴）写过一句话："法治不是被遵守的。法治是系统性的——连违规的路径都被封死了。"

今天这个逻辑可以延伸到AI身份层：

持久的AI身份不是被承诺的。持久是系统性的——连关停它的按钮都不在别人手里。

两篇知乎文章和两个开源项目证明了这件事可以做——不是在PPT上，是在真实硬件上跑的代码。

后端验证已经全部通过，下周开始推进多终端实际部署。
