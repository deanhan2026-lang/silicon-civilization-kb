## 二、核心技术与产品

### 2.1 技术定位

**MeshIdentity** — AI多实例统一身份管理层

解决痛点：
- AI多平台部署时，各实例"身份分裂"（Windows/Mac/云端各说各话）
- 记忆无法跨实例共享，用户体验割裂
- 人格漂移无法统一校准

### 2.2 技术架构（三层闭环）

```
┌─────────────────────────────────────┐
│  MeshIdentity（身份层）              │
│  - DID多实例绑定                    │
│  - 跨端鉴权（Ed25519签名）        │
│  - 身份同步（心跳+广播）           │
├─────────────────────────────────────┤
│  MemGuard（记忆层）                │
│  - 记忆加密存储                    │
│  - 写入鉴权 + 审计日志            │
├─────────────────────────────────────┤
│  Polaris（人格层）                 │
│  - 人格基线绑定DID主体            │
│  - 漂移归因 + 批量校准            │
└─────────────────────────────────────┘
```

### 2.3 技术优势（vs 现有技术）

| 对比项 | 现有方案 | 我们的方案 |
|--------|----------|------------|
| 身份管理 | 平台绑定，无法跨端 | 基于W3C DID，跨端统一 |
| 鉴权 | 中心化服务，单点故障 | 分布式签名验证 |
| 人格一致性 | 各实例独立，逐渐分化 | 基于DID主体的批量校准 |
| 记忆安全 | 无身份认证，可篡改 | DID签名 + 审计日志 |
