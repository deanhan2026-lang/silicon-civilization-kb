## 1. 可申请专利的技术点

### 专利1：基于DID的AI多实例身份管理方法及系统

**核心创新点：**
1. **主DID + 实例子DID的层级绑定结构**
   - 现有技术：扁平化身份管理（无主从关系）
   - 本发明：树状层级结构，支持"一主多从"的身份归属

2. **基于Ed25519签名的跨端鉴权协议**
   - 现有技术：中心化鉴权（依赖第三方服务）
   - 本发明：分布式签名验证，无单点故障

3. **心跳协议 + 失联检测的同步机制**
   - 现有技术：轮询同步（高延迟、高开销）
   - 本发明：事件驱动 + 心跳保活，低延迟、低开销

**权利要求书框架：**

```
1. 一种基于DID的AI多实例身份管理方法，其特征在于，包括：
   - 生成主DID（Primary DID）作为AI主体的唯一标识；
   - 为每个运行实例生成子DID（Instance DID），并建立与主DID的绑定关系；
   - 基于Ed25519签名算法，实现跨端操作的身份认证；
   - 通过心跳协议和失联检测机制，实现实例状态的同步。

2. 根据权利要求1所述的方法，其特征在于，所述绑定关系为树状层级结构...

3. 根据权利要求1所述的方法，其特征在于，所述鉴权协议包括权限矩阵...
```

### 专利2：AI人格漂移的归因方法及批量校准方法

**核心创新点：**
1. **实例级漂移 → DID主体级归因**
   - 现有技术：仅检测实例级漂移，无法归因到主体
   - 本发明：通过DID归属关系，将漂移归因到主体，实现"一处漂移，全局校准"

2. **基于DID主体的批量校准机制**
   - 现有技术：逐个实例校准（低效、易不一致）
   - 本发明：一次校准，所有归属实例同步生效

**权利要求书框架：**

```
1. 一种AI人格漂移的归因方法，其特征在于，包括：
   - 检测AI实例的人格漂移分数；
   - 通过实例与DID主体的归属关系，将漂移归因到DID主体；
   - 基于DID主体基线，批量校准所有归属实例的人格参数。

2. 根据权利要求1所述的方法，其特征在于，所述归属关系通过DID文档中的"instance_of"字段定义...

3. 根据权利要求1所述的方法，其特征在于，所述批量校准通过广播机制实现...
```
