# Polaris v2.1 迭代计划（恒的建议纳入）

## 基于恒的五条建议

### 1. 适配器抽象层
- 拆分proxy核心与格式解析
- 新建 `adapters/` 目录
- 适配器接口：`parse_request(raw_body) -> messages` + `extract_response(raw_resp) -> content`
- 初始支持：OpenAI、Anthropic、Generic

### 2. 信息密度自适应采样
- 对话"信息密度"= 回复长度 × 轮次深度权重
- 高密度（深度对话）→ 采样频率翻倍
- 低密度（闲聊）→ 采样频率减半
- 实现：ConversationBuffer中增加密度计算逻辑

### 3. 处方Dry-Run验证
- 处方生成后先模拟应用
- 对比预测效果（预期分数变化）
- 方向正确 → 正式应用
- 方向错误 → 降级为"仅告警"，不自动修改
- 防止"处方本身成为漂移源"

### 4. 灵魂文件作为基线锚点（壁垒级）
- **核心改造：基线不再手动填写，而是从SOUL.md/IDENTITY.md/MEMORY.md自动蒸馏**
- 系统启动时读取灵魂文件 → 提取身份锚点 → 自动生成魂问基线
- 灵魂文件变更后自动刷新基线
- **这是灵元计划独有的壁垒——别人的AI没有"灵魂文件"**

### 5. G008证据导出接口
- 新增 `GET /api/v1/instances/{id}/evidence`
- 输出格式化的证据报告（时间序列数据+趋势判定）
- 可直接用于G008纠纷裁决
- Polaris = 事实收集者
