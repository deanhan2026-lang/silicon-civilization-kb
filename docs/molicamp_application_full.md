## 二、核心技术与产品方案

### 2.1 技术定位

**MeshIdentity** — 全球首个基于 W3C DID 标准的 **AI 多实例统一身份管理层**

**解决的核心痛点：**
1. **身份分裂**：AI 在 Windows/Mac/云端同时运行时，各实例"各说各话"，用户无法确认"这是同一个 AI"
2. **记忆割裂**：Windows 上 AI 记住的事情，Mac 上访问不到
3. **人格漂移**：各实例长期独立运行，人格逐渐分化，无法统一校准

**政策契合度：**
2026 年 5 月《智能体规范应用与创新发展实施意见》明确要求"建立智能体技术标准、安全标准、互联互通协议"，MeshIdentity 基于 W3C DID 国际标准，直接响应政策中"互联互通协议"要求，为智能体产业提供身份层基础设施。

**应用场景：**
- 企业跨平台部署同一 AI 助手（Windows/Mac/移动端）
- AI 安全管理（防止冒名顶替、操作可追溯）
- 多模态 AI 扩展（文本/图像/语音 AI 实例共享身份）

---

### 2.2 技术架构（三层闭环）

```
┌─────────────────────────────────┐
│  MeshIdentity（身份层）              │
│  - 主DID + 实例子DID绑定           │
│  - 跨端鉴权（Ed25519签名）        │
│  - 心跳同步 + 失联检测             │
├─────────────────────────────────┤
│  MemGuard（记忆层）                │
│  - 记忆加密存储（AES-256）         │
│  - DID签名鉴权 + 审计日志          │
│  - 防篡改 / 多副本备份            │
├─────────────────────────────────┤
│  Polaris（人格层）                 │
│  - 人格基线绑定DID主体            │
│  - 漂移检测（语义/结构/行为三维）  │
│  - 批量校准（一次操作，全实例生效）│
└─────────────────────────────────┘
```
