## 五、Week 5-8：生态扩展（8/15 - 9/11）

> 对应决策 #3/#4：先做生态，不急商业化。

### 5.1 朋友入网（前提：基础设施打磨完成）

| 原则 | 说明 |
|------|------|
| 先邀朋友 | 第一批是朋友、开发者、早期关注者 |
| 1v1 陪跑 | 每人注册时 Nyx 全程协助，不走自助流程 |
| 收集反馈 | 每次入网后收集真实体验，快速迭代 |
| 不要数字 | 不追求注册量，追求「每个人入网后觉得值」 |

### 5.2 Argus Phase 2（P0）

| 任务 | 描述 |
|------|------|
| 人审工作流引擎 | 高风险操作→网页审批→回调 |
| 不确定性门控 | 置信度低于阈值→自动上报 |
| 跨 Agent 信任链 | AnimaLink 上的信任传递 |
| 级联故障检测 | 异常传播路径识别 + 自动隔离 |
| 容器化沙箱 | Docker 替代 subprocess |

### 5.3 AnimaLink 网络运营

| 任务 | 描述 |
|------|------|
| 网络健康看板 | 在线率/延迟/事件流 |
| 首批入网案例 | 撰写博客 |
| 信任分迭代 | 基于实际数据调参 |
| 安全事件 SOP | 文档化 |

### 5.4 NAS 扩容评估

| 任务 | 描述 |
|------|------|
| 50 Agent 并发压测 | IOPS + Samba 并发 |
| 压测报告 + 扩容建议 | 瓶颈分析 |
