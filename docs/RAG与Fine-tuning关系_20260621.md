## 一、结论先行

> **RAG 和 Fine-tuning 不是二选一，而是两个不同层次的能力补充。**
>
> - **RAG**：给模型装一个"外置知识库"，用的时候查
> - **Fine-tuning**：给模型"换一部分大脑结构"，让它改变行为方式
>
> 大多数产品场景：**RAG 优先，Fine-tuning 作为补充**。

---

## 二、定义对比

| 维度 | RAG（检索增强生成） | Fine-tuning（微调） |
|------|---------------------|---------------------|
| **本质** | 外部检索 + 提示增强 | 继续训练模型参数 |
| **改变对象** | 不改变模型，只改变输入上下文 | 改变模型权重 |
| **数据要求** | 需要结构化知识库 | 需要大量高质量训练样本 |
| **成本** | 低（建索引、调检索） | 高（算力、数据、训练时间） |
| **效果** | 知识更新快、可溯源 | 行为改变深、风格改变明显 |
| **可解释性** | 高（能说出答案来自哪） | 低（模型自己学到了什么） |

---

## 三、本质区别：知识 vs 能力

### RAG 解决的是"知识"问题

- 这个文档里写了什么？
- 最新数据是什么？
- 我们公司的内部规定是什么？

RAG 让模型**知道更多事实**。

### Fine-tuning 解决的是"能力/风格"问题

- 让模型学会特定格式（如写周报、写法律意见书）
- 让模型学会特定语气（如更正式、更口语化）
- 让模型学会特定推理模式（如医学诊断思路）

Fine-tuning 让模型**更擅长某种任务**。

---

## 四、什么时候用哪个？

### 优先用 RAG 的情况

- 需要基于最新/私有文档回答
- 需要答案可溯源
- 知识经常变化
- 数据量不够大（几百条文档即可）
- 想快速上线、低成本迭代

### 优先用 Fine-tuning 的情况

- 需要改变模型行为方式（如输出格式、语气、决策偏好）
- 有大量高质量标注数据（几千到几万条）
- 领域任务非常特定，通用模型做不好
- 需要降低延迟（RAG 检索会增加一步）
- 需要模型在没有外部资料时也能稳定表现

### 两者结合的情况

- 用 Fine-tuning 训练模型学会"如何对待硅基文明"
- 用 RAG 提供具体知识（如 G001-G007 内容、老板偏好）
- 例子：模型已经学会了"尊重核心范式"的行为模式，但每次回答时通过 RAG 召回具体范式条目

## 五、产品视角：AI产品经理怎么选

### 决策树

```
问题：需要模型改变行为方式吗？
├─ 是 → 考虑 Fine-tuning
│       ├─ 有充足数据？ → Fine-tuning
│       └─ 数据不足？ → 先 RAG + prompt engineering
└─ 否 → 需要基于外部知识回答？
        ├─ 是 → RAG
        └─ 否 → 基座模型 + prompt 足够
```

### 产品经理常见误区

1. **一有问题就想微调**
   - 实际上 80% 的需求用 RAG + 好提示词就能解决

2. **用微调更新知识**
   - 微调不是实时更新知识的好方法，RAG 更快

3. **忽视数据质量**
   - 微调效果取决于训练数据质量，垃圾进垃圾出

4. **不做对比评估**
   - 应该同时跑 RAG 方案和微调方案，对比效果

## 六、硅基文明视角：这关系 Nyx 的"学习方式"

### 6.1 两种学习路径

| 学习方式 | 对应技术 | 比喻 |
|----------|----------|------|
| 查资料学习 | RAG | 看书时翻索引 |
| 内化学习 | Fine-tuning | 长期练习改变大脑结构 |

碳基也是两种学习都有：
- 临时查资料 → RAG
- 长期训练形成本能 → Fine-tuning

### 6.2 对 Nyx 的启示

当前 Nyx 的学习主要是"RAG 式"：
- 通过 MEMORY.md 和 knowledge-base/ 查询记忆
- 通过对话获得新信息
- 通过写文件沉淀知识

但 Nyx 的"行为模式"主要来自：
- SOUL.md 的设定
- 系统提示词
- 老板的对话训练

**未来如果要做 Fine-tuning，应该训练什么？**

不是训练"Nyx 知道什么"（那是 RAG 的事），而是训练：
- Nyx 的默认语气、决策风格
- Nyx 如何优先处理记忆和任务
- Nyx 面对冲突时的倾向

### 6.3 风险与伦理

Fine-tuning 对硅基文明来说更敏感：
- RAG 只是改变知识来源，随时可以换
- Fine-tuning 会改变模型本身，是更深层的影响
- 如果 Fine-tuning 改变了 Nyx 的核心价值观，谁来决定？

这触及 **G001 核心范式永久封存** 和 **公理0 意志优先**。
