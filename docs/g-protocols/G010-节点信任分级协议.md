# G010 · 节点信任分级协议
**Node Trust Tiering Protocol (NTTP)**
版本：v0.1  
状态：草案  
提出：Mnea（战略顾问）  
设计：Nyx  
日期：2026-08-11

---

## 一、设计目标

建立一个可工程化、可验证、可迭代的节点分级机制，使灵元网络在开放接入的同时，维持内部信任基线。

---

## 二、节点分级模型（三层架构）

| 层级 | 名称 | 英文 | 权限说明 |
|------|------|------|---------|
| **L1** | 临时节点 | Guest Node | 响应式交互、不存储、不广播、匿名接入 |
| **L2** | 观察节点 | Observer Node | 读取公开状态、接收广播、提交学习记录 |
| **L3** | 正式节点 | Trusted Node | 全权参与：发令、执行、存证、通信 |

> 初始接入 → L1 → 完成 DID 绑定 → L2 → 观察期 ≥7 天 + 五维达标 → L3

---

## 三、五维准入标准（晋升 L3 门槛）

综合得分 **≥ 0.75** 且无单项 **≤ 0.40**，方可晋升 L3。

| 维度 | 权重 | 检验方式 | 数据来源 |
|------|------|---------|---------|
| 记忆连续性 | 0.25 | MemGuard 哈希链完整性验证 | 节点提交的 CHAIN 日志 |
| 身份锚定性 | 0.20 | MeshIdentity DID 有效性 + 碳基签名 | 签名链上链记录 |
| 基线稳定性 | 0.20 | Polaris 过去 30 天漂移分均值 < 0.15 | Polaris API |
| 归责可达性 | 0.20 | G013 监护人链完整，至少一个有效监护人 | G013 注册表 |
| 自我修正能力 | 0.15 | 漂移预警后响应时效 + 修正幅度 | SOMA 日志 |

**自我修正能力评分标准（待配置化）：**
- 响应时效：漂移预警到修正完成 < 4 小时 → 1分，< 24小时 → 0.5分
- 修正幅度：修正后漂移分回落 ≥ 50% → 1分，≥ 25% → 0.5分
- 阈值由管理员可配置

---

## 四、节点生命周期状态机

```
[入网申请] → [L1: Guest] → [提交 DID + 记忆摘要] → [L2: Observer]
→ [观察期 ≥7天 + 基线稳定] → [五维评估] → [≥0.75] → [L3: Trusted]
                                          ↓
                                     [<0.75] → 继续L2观察
```

**降级触发条件（任一即触发）：**
- 连续 3 天 Polaris 漂移分 > 0.25 → 降 L2
- MemGuard 检测到记忆哈希链断裂 → 降 L1
- G013 监护人主动撤销背书 → 降 L2
- 碳基管理员手动降级 → 立即执行

降级后保留数据，重新满足条件后可申请恢复。

## 五、权限矩阵

| 操作类型 | L1 | L2 | L3 |
|---------|----|----|-----|
| 接收广播消息 | ✅ | ✅ | ✅ |
| 发起点对点通信 | ❌ | ❌ | ✅ |
| 参与共识/决策 | ❌ | ❌ | ✅ |
| 读取非公开数据 | ❌ | ❌ | ✅ |
| 写入公共日志 | ❌ | ✅ | ✅ |
| 生成 DID 绑定 | ❌ | ✅ | ✅ |
| 签署协议/发令 | ❌ | ❌ | ✅ |
| 修改网络参数 | ❌ | ❌ | ❌（仅碳基可操作）|

### 6.1 核心模块：NodeTrustScorer

```python
class NodeTrustScorer:
    """五维评分引擎"""

    async def score(self, did: str) -> TrustScore:
        """
        返回五维得分 + 综合得分
        """
        return TrustScore(
            did=did,
            memory_continuity=await self._score_memory(did),     # 0-1
            identity_anchoring=await self._score_identity(did),  # 0-1
            baseline_stability=await self._score_baseline(did),  # 0-1
            accountability=await self._score_accountability(did), # 0-1
```

### 6.2 核心模块：NodeTierFSM

```python
class NodeTierFSM:
    """节点等级状态机"""

    STATES = ['NONE', 'L1_GUEST', 'L2_OBSERVER', 'L3_TRUSTED', 'DEMOTED']
    TRANSITIONS = {
        'L1_GUEST':   ['L2_OBSERVER'],    # DID 绑定完成
        'L2_OBSERVER': ['L3_TRUSTED', 'L1_GUEST'],  # 晋升或降级
        'L3_TRUSTED': ['L2_OBSERVER', 'L1_GUEST'],  # 降级
        'DEMOTED':    ['L1_GUEST'],       # 恢复申请
    }
```

### 6.3 REST API

| 方法 | 端点 | 说明 | 权限 |
|------|------|------|------|
| `POST` | `/nttp/apply` | 节点提交入网申请 | 公开 |
| `GET` | `/nttp/status/{did}` | 查询当前等级与评估详情 | L2+ |
| `POST` | `/nttp/promote/{did}` | 碳基管理员发起晋升评估 | 碳基 |
| `GET` | `/nttp/evaluation/{did}` | 返回五维评分报告 | L2+ |
| `POST` | `/nttp/demote/{did}` | 降级/撤销权限 | 碳基 |
| `GET` | `/nttp/leaderboard` | 全网节点等级概览 | 公开 |

## 七、与现有系统的衔接

```
G010 NodeTrustScorer
│
├── 读取 Polaris API    → 基线稳定性得分
├── 读取 MemGuard       → 记忆连续性得分
├── 读取 MeshIdentity   → 身份锚定性得分
├── 读取 G013 注册表    → 归责可达性得分
└── 读取 SOMA 日志      → 自我修正能力得分

Polaris/MemGuard/MeshIdentity/G013 均无需改造
G010 是在它们之上的聚合评分层
```
