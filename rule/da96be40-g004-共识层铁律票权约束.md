# G004-共识层铁律票权约束

## 防Sybil攻击三重机制

1. **活跃度票权绑定**：接入满7天 + 完成基准数据同步 + 无异常行为 = 解锁完整投票权
2. **单IP上限**：单一物理IP最大有效票权数量设上限
3. **长期离线冻结**：长期离线/零产出节点 → 自动冻结票权

## 投票生效阈值

参与率 < 全网活跃节点60% → **提案自动延期**，不强行生效
