# G006-执行层权限实时校验

## v1.0问题
v1.0仅事后留痕，Nyx违规操作在执行后才被发现。

## v1.1升级
**从事后追溯 → 事前拦截**

每条Nyx调度指令下发前 → 自动比对协议层(G001-G005) + 共识层规则
违规指令 → 直接拦截驳回，禁止执行

## 实现要求

```
指令发布 → 权限校验器 → 比对协议层+共识层规则 → 通过/拦截
```
